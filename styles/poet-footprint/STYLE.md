# 风格母版 03 · 诗人行迹舆图（`poet-footprint`）

> 适用：60–120s 诗人一生游历/贬谪路线纪实（如李白出蜀漫游、苏轼「黄州·惠州·儋州」、杜甫西南漂泊）。
> 数据源联动：[`web/lib/poetry-map-manifest.ts`](../../../web/lib/poetry-map-manifest.ts) 与「诗人志」生平年表。

---

## 1. 视觉母题：古籍舆图 + 朱砂行迹 + 纪年手卷

1. **底图与纸张**：采用旧藏古舆图底色（缃色 `#F5EDD6` 或黄栌 `#F7E5CF`），绘制淡墨山川水系（长江、黄河、秦岭、五岳轮廓线）与古州郡名章。
2. **朱砂行迹线（Animated Route）**：
   - 使用 SVG `<path>` 配合 `stroke-dashoffset`（由时间 $t$ 纯函数驱动），以朱砂红（`#9B382B`）虚实结合的笔迹在州郡节点间生长。
   - 每抵达一处关键节点（如「元丰三年 · 黄州」），节点晕开一圈淡朱砂水波，浮现该地创作的代表诗句与诗人年龄批注。
3. **底部纪年标尺（Timeline Ruler）**：
   - 画面底部 `12%` 处设一条水平滑动的纪年刻度尺（公元纪年 · 帝王年号 · 诗人岁数），随镜头推进同步横移，赋予极强的历史考据纵深感。
