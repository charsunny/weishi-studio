# 风格母版 05 · 活体实机宣发片（`living-promo`）

> 适用：30–60s 版本大更新宣传片（如微诗 8.0 横竖屏宣传片 `artifacts/promo-8.0`）、App Store 预览视频、节气专题合集预告。
> 融合 `lemo-opuscar/styles/living-screencast` 与东方编辑部排版（Editorial Typography）。

---

## 1. 核心技法：DOM 级高分仿真 + 真机实况混编

1. **拒绝死板贴图**：
   - 凡涉及界面交互（如二十四节气集章点亮、折叠屏 iPhone Duo 展开、诗音播放器进度与高亮、画屏三比例切换），优先使用 **1:1 高分 DOM 组件 + `render(t)` 状态驱动**，确保放大特写时文字边缘锐利如刀。
   - 凡涉及 Metal 实时着色器与复杂手势（如真机画屏山水录屏），使用内嵌 `<video muted playsinline>` 并由导出器逐帧同步 `currentTime` + `seeked` 截帧。
2. **节奏编排（50s 黄金九幕结构）**：
   - `0–6s` 品牌情绪立意（明月/远山/书法笔刷收拢为图标）
   - `5–11s` 版本总Slogan（水墨揭幕 + 逐字墨洇 + 朱印）
   - `11–45s` 四至五个核心功能切面（每幕 `5–7s`，遵循「左/上极简大标题 + 右/下活体设备舞台」的呼吸节奏，浅宣与深鸦青交替制造视觉起伏）
   - `45–50s` 品牌收尾定帧（App Icon + Slogan + App Store 搜索引导）
